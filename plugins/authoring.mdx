A plugin implements the `mapper` interface of the `processor` world, defined in `.tangent/wit/processor.wit`. `tangent plugin compile` writes that WIT into the plugin's directory from the tangent that compiles it, so a plugin always builds against the interface of the runtime that will run it.

The quickest start is [`tangent plugin scaffold`](/cli/plugin/scaffold), which writes a working plugin with all three methods below.

## Interface

The interface has three methods to implement.

### Metadata

The name and version of your plugin.

### Probe

Tells the host which records to send to the plugin. A probe returns a list of selectors, and a record that matches any selector is sent. In a selector, a record must match every predicate in `all`, at least one in `any` (when `any` isn't empty), and none in `none`. The predicates are `has`, `eq`, `prefix`, `in`, `gt`, and `regex`, each on a field path.

<Tabs>
  <Tab title="Go">
    <CodeGroup>

    ```go main.go
    import (
        tangent_sdk "github.com/ethanblackburn/tangent-sdk-go"
    )

    var selectors = []tangent_sdk.Selector{
        {
            All: []tangent_sdk.Predicate{
                tangent_sdk.EqString("source.name", "myservice"),
            },
        },
    }
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Python">
    <CodeGroup>

    ```python mapper.py
    def probe(self) -> List[mapper.Selector]:
        # Match logs where source.name == "myservice"
        return [
            mapper.Selector(
                any=[],
                all=[
                    mapper.Pred_Eq(
                        ("source.name", log.Scalar_Str("myservice"))
                    )
                ],
                none=[],
            )
        ]
    ```

This probe selects every record with

```json
{"source": {"name": "myservice"}}
```

or with the literal key

```json
{"source.name": "myservice"}
```

The probe is the plugin's filter. A record that no plugin on a fan-out selects is dropped and counted (see [DAG](/configuration/dag)).

### ProcessLogs

The business logic of your plugin. It gets a batch of `log.Logview` handles, which read the record's JSON from the host, and returns its output records as newline-delimited JSON, one line per record. Returning fewer lines than it got drops records. Returning an error drops the batch, unless the plugin's [`drop_on_error`](/configuration/plugins) is `false`.

Performance note: prefer to fetch scalar values from the log. Scalars don't allocate on the heap, while fetching lists and maps does, which hurts performance.

<Tabs>
  <Tab title="Go">
    <CodeGroup>

    ```go main.go
    import (
        tangent_sdk "github.com/ethanblackburn/tangent-sdk-go"
    )

    //easyjson:json
    type ExampleOutput struct {
        Msg string `json:"message"`
    }

    func ExampleMapper(lv tangent_sdk.Log) (ExampleOutput, error) {
        var out ExampleOutput
        if msg := lv.GetString("msg"); msg != nil {
            out.Msg = *msg
        }
        return out, nil
    }

    func init() {
        tangent_sdk.Wire[ExampleOutput](
            Metadata,
            selectors,
            ExampleMapper, // per-log handler
            nil,           // batch handler
        )
    }

    func main() {}
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Python">
    <CodeGroup>

    ```python mapper.py
    def process_logs(self, logs: List[log.Logview]) -> bytes:
        buf = bytearray()
        for lv in logs:
            with lv:
                msg = lv.get("msg")
                value = msg.value if msg is not None else ""
                buf.extend(json.dumps({"message": value}).encode() + b"\n")
        return bytes(buf)
    ```

    use exports::tangent::logs::mapper::Guest;
    use tangent::logs::log::{Logview, Scalar};

    #[derive(Default, Serialize)]
    struct ExampleOutput {
        message: String,
    }

    fn string_from_scalar(s: Scalar) -> Option<String> {
        match s {
            Scalar::Str(v) => Some(v),
            _ => None,
        }
    }

    fn process_logs(input: Vec<Logview>) -> Result<Vec<u8>, String> {
        let mut buf = Vec::new();

        for lv in input {
            let mut out = ExampleOutput::default();

            if let Some(val) = lv.get("msg").and_then(string_from_scalar) {
                out.message = val;
            }

            let json_line = serde_json::to_vec(&out).map_err(|e| e.to_string())?;
            buf.extend(json_line);
            buf.push(b'\n');
        }

        Ok(buf)
    }

In Go, the SDK serializes what your handler returns: `Wire` takes a per-log handler, which returns one output per record, or a batch handler, which takes the whole batch and returns a slice (see the next section).

## What else a plugin can call

Besides `log`, the `processor` world gives a plugin these host interfaces:

| interface | what it does | see |
|---|---|---|
| `config` | `get(key)`: the plugin's `config` settings from the pipeline config | [Plugins](/configuration/plugins) |
| `state` | `get`, `set`, `incr`, `del`, `scan`, and `begin`/`commit`/`rollback`: keyed state shared by every worker | [State](/configuration/runtime#state) |
| `enrichment` | `lookup(table, key)`: reference data loaded once per process | [Enrichment tables](/configuration/enrichment-tables) |
| `remote` | `call-batch(requests)`: HTTP requests made by the host | below |

## Enriching logs

Plugins can make network calls to enrich logs. In this example, the plugin collects the unique IPs in a batch, asks a remote API about each one in a single batched call, and merges the answers back into the output. The Go, Python, and Rust versions behave the same.

<Tabs>
  <Tab title="Go">
    <CodeGroup>

    ```go main.go
    package main

    import (
        "encoding/json"
        "fmt"
        "net/url"

        tangent_sdk "github.com/ethanblackburn/tangent-sdk-go"
        "github.com/ethanblackburn/tangent-sdk-go/http"
    )

    var Metadata = tangent_sdk.Metadata{
        Name:    "ip-country-enrichment",
        Version: "0.1.0",
    }

    var selectors = []tangent_sdk.Selector{
        {
            All: []tangent_sdk.Predicate{
                tangent_sdk.Has("ip_address"),
            },
        },
    }

    //easyjson:json
    type EnrichedOutput struct {
        IPAddress string `json:"ip_address"`
        Country   string `json:"country"`
        Service   string `json:"service"`
    }

    func EnrichMapper(lvs []tangent_sdk.Log) ([]EnrichedOutput, error) {
        outs := make([]EnrichedOutput, len(lvs))
        ipToIdx := make(map[string][]int)

        // 1. Extract IPs and services
        for i, lv := range lvs {
            if svc := lv.GetString("service"); svc != nil {
                outs[i].Service = *svc
            }
            if ip := lv.GetString("ip_address"); ip != nil && *ip != "" {
                outs[i].IPAddress = *ip
                ipToIdx[*ip] = append(ipToIdx[*ip], i)
            }
        }
        if len(ipToIdx) == 0 {
            return outs, nil
        }

        // 2. One request per unique IP, all sent in one batch
        reqs := make([]http.Request, 0, len(ipToIdx))
        for ip := range ipToIdx {
            reqs = append(reqs, http.Request{
                ID:     ip,
                Method: http.MethodGet,
                URL:    "https://ipinfo.io/" + url.QueryEscape(ip),
            })
        }
        resps, err := http.CallBatch(reqs)
        if err != nil {
            return nil, fmt.Errorf("remote batch call failed: %w", err)
        }

        // 3. Assign each country back to its records
        for _, resp := range resps {
            if resp.Error != nil && *resp.Error != "" {
                return nil, fmt.Errorf("remote error for ip %s: %s", resp.ID, *resp.Error)
            }
            if resp.Status != 200 {
                return nil, fmt.Errorf("remote returned status %d for ip %s", resp.Status, resp.ID)
            }
            var payload struct {
                Country string `json:"country"`
            }
            if err := json.Unmarshal(resp.Body, &payload); err != nil {
                return nil, fmt.Errorf("decoding the response for %s: %w", resp.ID, err)
            }
            for _, i := range ipToIdx[resp.ID] {
                outs[i].Country = payload.Country
            }
        }
        return outs, nil
    }

    func init() {
        tangent_sdk.Wire[EnrichedOutput](
            Metadata,
            selectors,
            nil,          // per-log handler
            EnrichMapper, // batch handler
        )
    }

    func main() {}
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Python">
    <CodeGroup>

    ```python mapper.py
    from typing import Dict, List

    import json
    import wit_world
    from componentize_py_types import Err
    from wit_world.exports import mapper
    from wit_world.imports import log, remote


    class Mapper(wit_world.WitWorld):
        def metadata(self) -> mapper.Meta:
            return mapper.Meta(name="ip-country-enrichment", version="0.1.0")

        def probe(self) -> List[mapper.Selector]:
            return [mapper.Selector(any=[], all=[mapper.Pred_Has("ip_address")], none=[])]

        def process_logs(self, logs: List[log.Logview]) -> bytes:
            outs = []
            ip_to_idxs: Dict[str, List[int]] = {}

            # 1. Extract IPs and service names
            for i, lv in enumerate(logs):
                with lv:
                    service = lv.get("service")
                    ip = lv.get("ip_address")

                    outs.append({
                        "service": service.value if service else "",
                        "ip_address": ip.value if ip else "",
                        "country": "",
                    })

                    if ip and ip.value:
                        ip_to_idxs.setdefault(ip.value, []).append(i)

            # 2. One request per unique IP, all sent in one batch
            if ip_to_idxs:
                reqs = [
                    remote.Request(
                        id=ip,
                        method=remote.Method.GET,
                        url=f"https://ipinfo.io/{ip}",
                        headers=[],
                        body=b"",
                        timeout_ms=None,
                        cache_ttl_ms=None,
                    )
                    for ip in ip_to_idxs
                ]
                resps = remote.call_batch(reqs)

                # 3. Assign each country back to its records
                for resp in resps:
                    if resp.error:
                        raise Err(f"remote error for ip {resp.id}: {resp.error}")
                    if resp.status != 200:
                        raise Err(f"unexpected status {resp.status} for ip {resp.id}")
                    country = json.loads(resp.body).get("country", "")
                    for i in ip_to_idxs[resp.id]:
                        outs[i]["country"] = country

            # 4. One JSON line per output record
            buf = bytearray()
            for o in outs:
                buf.extend(json.dumps(o).encode() + b"\n")
            return bytes(buf)
    ```

  <Tab title="Rust">
    <CodeGroup>

    ```rust lib.rs
    use serde::{Deserialize, Serialize};
    use std::collections::HashMap;

    wit_bindgen::generate!({
        path: ".tangent/wit",
        world: "processor",
        generate_all,
    });

    use exports::tangent::logs::mapper::{Guest, Meta, Pred, Selector};
    use tangent::logs::log::{Logview, Scalar};
    use tangent::logs::remote::{call_batch, Method, Request};

    struct Component;

    export!(Component);

    fn string_from_scalar(s: Scalar) -> Option<String> {
        match s {
            Scalar::Str(v) => Some(v),
            _ => None,
        }
    }

    #[derive(Default, Serialize)]
    struct EnrichedOutput {
        ip_address: String,
        country: String,
        service: String,
    }

    #[derive(Deserialize)]
    struct IpInfo {
        country: Option<String>,
    }

    impl Guest for Component {
        fn metadata() -> Meta {
            Meta {
                name: "ip-country-enrichment".to_string(),
                version: "0.1.0".to_string(),
            }
        }

        fn probe() -> Vec<Selector> {
            vec![Selector {
                any: Vec::new(),
                all: vec![Pred::Has("ip_address".to_string())],
                none: Vec::new(),
            }]
        }

        fn process_logs(input: Vec<Logview>) -> Result<Vec<u8>, String> {
            let mut outs = Vec::with_capacity(input.len());
            let mut ip_to_idxs: HashMap<String, Vec<usize>> = HashMap::new();

            // 1. Extract IPs and services
            for (i, lv) in input.iter().enumerate() {
                let mut out = EnrichedOutput::default();
                if let Some(svc) = lv.get("service").and_then(string_from_scalar) {
                    out.service = svc;
                }
                if let Some(ip) = lv.get("ip_address").and_then(string_from_scalar) {
                    if !ip.is_empty() {
                        ip_to_idxs.entry(ip.clone()).or_default().push(i);
                    }
                    out.ip_address = ip;
                }
                outs.push(out);
            }

            // 2. One request per unique IP, all sent in one batch
            if !ip_to_idxs.is_empty() {
                let reqs: Vec<Request> = ip_to_idxs
                    .keys()
                    .map(|ip| Request {
                        id: ip.clone(),
                        method: Method::Get,
                        url: format!("https://ipinfo.io/{ip}"),
                        headers: Vec::new(),
                        body: Vec::new(),
                        timeout_ms: None,
                        cache_ttl_ms: None,
                    })
                    .collect();

                // 3. Assign each country back to its records
                for resp in call_batch(&reqs)? {
                    if let Some(err) = resp.error.filter(|e| !e.is_empty()) {
                        return Err(format!("remote error for {}: {err}", resp.id));
                    }
                    if resp.status != 200 {
                        return Err(format!("unexpected status {} for ip {}", resp.status, resp.id));
                    }
                    let info: IpInfo = serde_json::from_slice(&resp.body).map_err(|e| e.to_string())?;
                    let country = info.country.unwrap_or_default();
                    for &i in &ip_to_idxs[&resp.id] {
                        outs[i].country = country.clone();
                    }
                }
            }

            // 4. One JSON line per output record
            let mut buf = Vec::new();
            for o in outs {
                serde_json::to_writer(&mut buf, &o).map_err(|e| e.to_string())?;
                buf.push(b'\n');
            }
            Ok(buf)
        }
    }
    ```

`tangent plugin test` blocks remote calls unless you pass `--enable-http`, and `runtime.disable_remote_calls: true` blocks them in a pipeline. A blocked call doesn't fail: each request gets status `204`, no headers, and an empty body, so the examples above return an error on status 204, and fail their test, when `--enable-http` is left out. A remote call inside an open state transaction fails.
