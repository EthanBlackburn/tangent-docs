---
title: "Socket"
description: "Ingest NDJSON from a local Unix domain socket."
---

The **Socket source** reads logs from a local Unix domain socket (UDS). It's a simple way to connect local producers, such as agents, sidecars, or log forwarders, directly to Tangent.

---

## Schema

<ParamField path="type" type="string" required>
Must be `socket`.
</ParamField>

<ParamField path="socket_path" type="string">
Path to the Unix domain socket to listen on. Defaults to `/tmp/sidecar.sock`. A socket's path has to be shorter than about 100 bytes (104 on macOS, 108 on Linux). A longer one logs `socket listener error: path must be shorter than SUN_LEN`, and the pipeline runs on without the source, so use a short absolute path or one relative to the working directory.
</ParamField>

---

## Example

```yaml tangent.yaml icon=plug
sources:
  socket_main:
    type: socket
    socket_path: "/tmp/sidecar.sock"
```

---

## Behavior

* Tangent listens on the socket path and accepts connections from any local process.
* Producers write newline-delimited JSON, one object per line. The socket source takes no `decoding` block.
* When the source closes, Tangent flushes any buffered records before shutdown.

---

## Common use cases

| Use case                 | Example                                                             |
| ------------------------ | ------------------------------------------------------------------- |
| Local log forwarder      | An app writes logs to `/tmp/sidecar.sock` instead of stdout         |
| Sidecar integration      | Send structured logs from a container to Tangent                    |
| Testing and benchmarking | `tangent bench` drives a config's socket source as it does a TCP one |
