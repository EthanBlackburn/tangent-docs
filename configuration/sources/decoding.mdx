---
title: "Decoding"
description: "How the file, MSK, and SQS sources parse the bytes they read."
---

The `decoding` block tells a source **how to interpret the bytes it reads**. The `file`, `msk`, and `sqs` sources require it. The `tcp` and `socket` sources take newline-delimited JSON and have no `decoding` block.

It has two parts, each a small block with a `type`:

- `format`: how to parse the bytes
- `compression`: whether the bytes are compressed (detected by default)

```yaml
decoding:
  format: { type: ndjson }
  compression: { type: auto }
```

---

## Schema

<ParamField path="decoding.format.type" type="string" required>
How to parse the payload.

- `ndjson`: one JSON object per line.
- `json`: one JSON value. An array becomes one record per element, and an object becomes one record.
- `json-array`: the same as `json`. Use it to say that the payload is a batch.
- `msgpack`: a MessagePack value, decoded the same way as `json`.
- `text`: read the same as `ndjson`, so each line must be a JSON object.

A `json`, `json-array`, or `msgpack` payload that doesn't parse is logged with a warning and passed on as lines.
</ParamField>

<ParamField path="decoding.compression.type" type="string">
Controls decompression. Defaults to `auto`.

- `auto`: detect it, as described below.
- `none`: don't decompress.
- `gzip`: always gzip.
- `zstd`: always Zstandard.

With `auto`, Tangent checks, in order:
1. **Metadata**, such as an S3 object's `Content-Encoding`, for `gzip`, `zstd`, or `identity`/`none`.
2. The **file name**: `.gz` or `.gzip` means gzip, and `.zst` or `.zstd` means Zstandard.
3. The **magic bytes**: `1F 8B` for gzip, `28 B5 2F FD` for Zstandard.

If none of these match, Tangent assumes `none`.
</ParamField>

## Examples

### MSK (Kafka)

```yaml tangent.yaml icon=download
sources:
  kafka_in:
    type: msk
    bootstrap_servers: "b-1.example.com:9092,b-2.example.com:9092"
    topic: logs
    auth:
      mode: scram
      username: tangent
      password: "${MSK_PASSWORD}"
    decoding:
      format: { type: ndjson }
      compression: { type: auto }
```

### File (compressed batch JSON)

```yaml tangent.yaml icon=file
sources:
  access_logs:
    type: file
    path: /var/log/app/access.json.zst
    decoding:
      format: { type: json-array }
      compression: { type: auto }   # detects zstd from the file name or magic bytes
```

### SQS (MessagePack)

```yaml tangent.yaml icon=cloud
sources:
  app_queue:
    type: sqs
    queue_url: https://sqs.us-east-1.amazonaws.com/123456789012/queue
    decoding:
      format: { type: msgpack }
      compression: { type: none }
```
