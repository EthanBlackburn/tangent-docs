Sources define **where Tangent reads data from**. Each source is declared under a name of your choosing in `sources:`, and the [DAG](/configuration/dag) sends its records on by that name.

---

## Source types

| Type | Reads | Docs |
|------|-------|------|
| `tcp` | NDJSON over TCP | [TCP](/configuration/sources/tcp) |
| `socket` | NDJSON over a local Unix domain socket | [Socket](/configuration/sources/socket) |
| `file` | one file, read once at start | [File](/configuration/sources/file) |
| `msk` | a Kafka topic on Amazon MSK | [MSK](/configuration/sources/msk) |
| `sqs` | messages from an Amazon SQS queue | [SQS](/configuration/sources/sqs) |
| `cloudtrail` | a CloudTrail trail's files, every account of an organization trail | [packs/aws](https://github.com/EthanBlackburn/tangent/tree/main/packs/aws#use-it) |
| `github_audit` | a GitHub organization's audit log API | [packs/github](https://github.com/EthanBlackburn/tangent/tree/main/packs/github) |
| `okta` | Okta's System Log API | [packs/okta](https://github.com/EthanBlackburn/tangent/tree/main/packs/okta) |
| `google_workspace` | Google Workspace login, token, Drive, and admin activity | [packs/google_workspace](https://github.com/EthanBlackburn/tangent/tree/main/packs/google_workspace) |
| `github_webhook` | GitHub webhook deliveries over HTTP | [examples/githubwebhooks](https://github.com/EthanBlackburn/tangent/tree/main/examples/githubwebhooks) |
| `sqlite` | one partition of a `sqlite` sink's table, read back in batches | [README](https://github.com/EthanBlackburn/tangent#keeping-records-and-reading-them-back) |

The `cloudtrail`, `github_audit`, `okta`, and `google_workspace` sources are what the [packs](/packs/overview) read. The pack's README lists each one's config block and the credentials it needs.

---

## Common configuration

<ParamField path="type" type="string" required>
Selects the source type, from the table above.
</ParamField>

<ParamField path="decoding" type="object">
How the `file`, `msk`, and `sqs` sources parse the bytes they read: format and compression. These three require it. See [Decoding](/configuration/sources/decoding).
</ParamField>

Each source type accepts only its own keys. A misspelled key is an error, not a silent default.

---

## Example

```yaml tangent.yaml icon=download
sources:
  events:
    type: tcp
    bind_address: 0.0.0.0:9000
  kafka_in:
    type: msk
    bootstrap_servers: "b-1.example.com:9092,b-2.example.com:9092"
    topic: logs
    auth:
      mode: scram
      username: tangent
      password: "${MSK_PASSWORD}"
    decoding:
      format: { type: ndjson }
```

---

## Behavior

* Each source runs on its own task in the runtime.
* Records are batched in memory and flushed to the workers by size or age ([`batch_size` and `batch_age`](/configuration/runtime)).
* A source's name can't also name a plugin, inference node, or sink.
