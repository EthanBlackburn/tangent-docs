---
title: "Compression"
description: "How a sink compresses data before writing it."
---

The `compression` block, set on a sink beside `encoding`, defines **how the sink compresses what it writes** to S3 or to a rolling file.

---

## Schema

<ParamField path="compression.type" type="string" required>
The compression algorithm.

- `none`: no compression.
- `gzip`: Gzip.
- `zstd`: Zstandard, fast with a high ratio. The default.
- `snappy`: Snappy, for Avro.
- `deflate`: Deflate, for Avro.
</ParamField>

<ParamField path="compression.level" type="int">
Compression level, optional.

| Algorithm | Default | Notes |
|-----------|---------|-------|
| `gzip` | `6` | `0` to `9`; higher is smaller and slower |
| `zstd` | `3` | higher is smaller and slower |
</ParamField>

---

## Behavior

- For **NDJSON** and **JSON**, `gzip` and `zstd` compress the whole file, and Tangent appends `.gz` or `.zst` to its name.
- For **Parquet**, compression applies to the data inside the file, and the file isn't wrapped again. Parquet takes `none`, `gzip`, or `zstd`.
- For **Avro**, compression applies to the file's blocks. Avro takes `none`, `deflate`, `snappy`, or `zstd`. With `gzip`, Avro blocks are written uncompressed.
- The [File sink](/configuration/sinks/file) doesn't compress.

---

## Examples

### Default (Zstandard level 3)

```yaml tangent.yaml icon=upload
sinks:
  out:
    type: s3
    bucket_name: my-bucket
    compression:
      type: zstd
      level: 3
```

### Gzip at level 9

```yaml tangent.yaml icon=upload
sinks:
  out:
    type: s3
    bucket_name: my-bucket
    compression:
      type: gzip
      level: 9
```

### No compression

```yaml tangent.yaml icon=upload
sinks:
  out:
    type: s3
    bucket_name: my-bucket
    compression:
      type: none
```

---

## Recommended use

| Scenario                      | Compression                 |
| ----------------------------- | --------------------------- |
| High-throughput pipelines     | `zstd` (fast and efficient) |
| Archival or long-term storage | `gzip` or `zstd`            |
| Parquet                       | `zstd`                      |
| Avro                          | `zstd`, `snappy`, or `deflate` |
| Local testing                 | `none`                      |
