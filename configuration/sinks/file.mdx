---
title: "File"
description: "Append NDJSON to a local file."
---

The **File sink** appends every write to one file at `path`, as newline-delimited JSON. Because each write is appended to the same file, only NDJSON survives it, so this sink takes no other encoding: a config that gives it another `encoding` fails to load. To write Parquet, Avro, or JSON files, use a [rolling file sink](/configuration/sinks/rolling-file).

---

## Schema

<ParamField path="type" type="string" required>
Must be `file`.
</ParamField>

<ParamField path="path" type="string" required>
The file to append to, relative to the working directory.
</ParamField>

---

## Example

```yaml tangent.yaml icon=file
sinks:
  local_file:
    type: file
    path: /tmp/out.ndjson
```

The file sink writes plain NDJSON. It doesn't compress what it writes.
