---
title: "Encoding"
description: "How a sink serializes records before writing them."
---

The `encoding` block defines **how a sink serializes records** before it writes them: as NDJSON, a JSON array, Avro, or Parquet. Records travel through the pipeline as NDJSON, so `ndjson` is the default and costs nothing extra.

---

## Schema

<ParamField path="encoding.type" type="string" required>
Output format. Defaults to `ndjson`.

- `ndjson`: newline-delimited JSON, one record per line.
- `json`: one JSON array of records per file.
- `avro`: Apache Avro, with the schema given in `schema`.
- `parquet`: Apache Parquet, with the columns given in `schema`.

The [File sink](/configuration/sinks/file) takes `ndjson` only. Use a [rolling file](/configuration/sinks/rolling-file) or [S3](/configuration/sinks/s3) sink for the others.
</ParamField>

<ParamField path="encoding.schema" type="string | map">
Required for `avro` and `parquet`.

- For `avro`, the Avro schema itself, as JSON text. Each record is written as an Avro map, so give a map schema, such as `{"type": "map", "values": "string"}`. A record schema isn't supported yet: it passes the check at startup, then every file fails to encode.
- For `parquet`, the file's columns, in order, each a name and a type: `string`, `int` (64 bits), `float` (a double), `bool`, or `timestamp` (milliseconds in UTC, read from RFC 3339 text in any zone). A nested map of columns is a struct, for a nested object. Every column can be null.
</ParamField>

<ParamField path="encoding.record_column" type="string">
For `parquet`: also keep each record, as its JSON line, in a string column of this name, so a query can still reach the fields the schema leaves out.
</ParamField>

## Examples

### NDJSON (default)

```yaml tangent.yaml icon=upload
sinks:
  out:
    type: s3
    bucket_name: my-bucket
    encoding:
      type: ndjson
    compression:
      type: zstd
      level: 3
```

### Parquet

```yaml tangent.yaml icon=upload
sinks:
  lake:
    type: rolling_file
    path: lake/logs/%Y/%m/%d/%H
    wal_path: lake/wal
    encoding:
      type: parquet
      record_column: record
      schema:
        ts: timestamp
        source: string
        _norm: { org: string, actor: string }
    compression:
      type: zstd
```

A record the schema can't read (a field with a type the schema doesn't give it, a time Arrow can't parse) doesn't fail its file. It's kept in `record_column` with its typed columns null, or dropped if there's no record column or it isn't JSON. `tangent_sink_records_unfit_total{fate="kept"|"dropped"}` counts them.

### Avro

```yaml tangent.yaml icon=upload
sinks:
  events_avro:
    type: s3
    bucket_name: my-bucket
    encoding:
      type: avro
      schema: '{"type": "map", "values": "string"}'   # each record a map of strings
    compression:
      type: deflate
```

---

## Defaults

| Setting             | Default  |
| ------------------- | -------- |
| `encoding.type`     | `ndjson` |
| `compression.type`  | `zstd`   |
| `compression.level` | `3`      |
