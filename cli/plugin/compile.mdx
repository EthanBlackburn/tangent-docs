---
title: 'tangent plugin compile'
description: 'Compile the plugins a config names to WASM.'
mode: "center"
---

`tangent plugin compile` builds each plugin a config names into a WASM component the runtime can load.

```bash
tangent plugin compile --config tangent.yaml
```

**Options**

* `--config <file>` (required): the config whose plugins to compile. Each plugin's `path` and `module_type` say what to build.
* `--plugin <name>`: compile only this plugin.
* `--wit <dir>`: compile every plugin against this WIT directory (with the `processor` world). Without it, `compile` first writes this tangent's own WIT into each plugin's `.tangent/wit`, so a plugin always builds against the interface of the tangent that compiles it.

**Outputs**, in [`runtime.plugins_path`](/configuration/runtime) (`plugins/` by default), relative to the config:

* `<name>.component.wasm`: the portable component
* `<name>.cwasm`: the component precompiled for this machine, which `tangent run` loads

A plugin with `prebuilt` and no `path` is skipped: [`tangent plugin fetch`](/cli/plugin/fetch) gets it.

<Note>
With Go 1.27, the Go SDK's code generator fails with `internal error: package "github.com/ethanblackburn/tangent-sdk-go" without types was imported`. Go 1.25 works: `GOTOOLCHAIN=go1.25.4 tangent plugin compile --config tangent.yaml`. TinyGo 0.43 needs Go 1.25 through 1.27.
</Note>
