---
title: 'tangent bench'
description: 'Measure a pipeline’s throughput and latency.'
mode: "center"
---

Send load to a running pipeline to measure its throughput and latency. Start the pipeline with `tangent run` first, then point `tangent bench` at the same config: it connects to the config's TCP or socket source and reads the runtime's metrics.

```bash
tangent run --config tangent.yaml
# in another terminal
tangent bench --config tangent.yaml --seconds 30 --payload tests/input.json
```

**Options**

* `--config <file>` (required): the pipeline's config. Bench sends to its source.
* `--payload <file>` (required): the records to send, as a JSON object or an array of objects. Bench sends them over and over.
* `--seconds <n>`: how long to measure, after a warmup. Defaults to `15`.
* `--connections <n>`: concurrent connections. Defaults to `2`.
* `--synthesize`: treat the payload as a template and generate varied records from it, such as the `tests/bench.json` a scaffolded plugin comes with.
* `--max-bytes <n>`: cap on the bytes per write (`0` disables it). Defaults to `65536`.
* `--metrics-url <url>`: the runtime's Prometheus endpoint. Defaults to `http://127.0.0.1:9184/metrics`.
* `--disable-metrics`: don't read the runtime's metrics. Use it only when benchmarking something other than `tangent run`.

To compare languages the way the project's benchmarks do:

```bash
tangent plugin compile --config examples/rust/tangent.yaml
tangent run --config examples/rust/tangent.yaml &
tangent bench --config examples/rust/tangent.yaml --seconds 20 --connections 16 --payload examples/rust/tests/bench.json --synthesize
```

Bench in CI before you ship changes to a critical transform.
