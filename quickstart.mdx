## Goal

Create a WASM plugin, test it, run the pipeline locally, then benchmark it.

<Steps>
  <Step title="Install Tangent">

```bash
cargo install --git https://github.com/EthanBlackburn/tangent tangent-cli
```

See [Installation](/install) for other ways to install.
  </Step>
  <Step title="Scaffold a plugin">

```bash
# Create a new plugin in Python, Go, or Rust
tangent plugin scaffold --lang python --name hello-logs
# or:
tangent plugin scaffold --lang go --name hello-logs
# or:
tangent plugin scaffold --lang rust --name hello-logs

cd hellologs
```

Scaffold creates a minimal working plugin in `hellologs/` (dashes are dropped from the name), with tests and a `tangent.yaml` that wires a TCP source on port 9000 through the plugin to a `blackhole` sink. If the language's toolchain isn't installed yet, run `./setup.sh` in the new directory.
  </Step>
  <Step title="Compile">

```bash
tangent plugin compile --config tangent.yaml
```

This writes `plugins/hellologs.component.wasm` and `plugins/hellologs.cwasm`.
  </Step>
  <Step title="Test">

```bash
tangent plugin test --config tangent.yaml
```

The plugin's output for `tests/input.json` must match `tests/expected.json`.
  </Step>
  <Step title="Run the pipeline">

```bash
tangent run --config tangent.yaml
```

Your pipeline is now running and listening on port 9000. Send it a record from another terminal, and see in the runtime's metrics that the plugin read it:

```bash
echo '{"msg": "my log", "source": {"name": "myservice"}}' | nc -w 1 localhost 9000
curl -s localhost:9184/metrics | grep tangent_guest_bytes_total
```
  </Step>
  <Step title="Benchmark">

With the pipeline still running, in another terminal:

```bash
tangent bench --config tangent.yaml --seconds 30 --payload tests/input.json
```
  </Step>
</Steps>
