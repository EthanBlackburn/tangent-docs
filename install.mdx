## Overview

Tangent ships as a single executable, `tangent`.

## Installation

<Tabs>
  <Tab title="macOS & Linux">
    <CodeGroup>

    ```bash curl
    curl --proto '=https' --tlsv1.2 -LsSf https://github.com/EthanBlackburn/tangent/releases/latest/download/tangent-cli-installer.sh | sh
    tangent --version
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Homebrew">
    <CodeGroup>

    ```bash sh
    brew tap telophasehq/telophase
    brew install tangent-cli
    tangent --version
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Docker">
    <CodeGroup>

    ```bash docker
    docker pull ghcr.io/telophasehq/tangent-toolchain
    docker run --rm --init ghcr.io/telophasehq/tangent-toolchain help
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Cargo">
    <CodeGroup>

    ```bash cargo
    cargo install --git https://github.com/EthanBlackburn/tangent tangent-cli
    ```

    </CodeGroup>
  </Tab>
</Tabs>

<Warning>
These docs follow tangent's `main` branch. The latest release, 0.1.9, predates [`include:`](/configuration/include), [enrichment tables](/configuration/enrichment-tables), [packs](/packs/overview), and DAG edges that name nodes alone (`from: cloudtrail`). Until the next release, install with Cargo, or build from a checkout with `cargo install --path crates/cli --locked`.
</Warning>

## Plugin toolchains

Running a pipeline needs only `tangent`. Compiling a plugin also needs its language's toolchain (TinyGo, componentize-py, or cargo-component, plus wasm-tools). A scaffolded plugin's `setup.sh` installs them. See [CLI dependencies](/cli/overview#dependencies).
